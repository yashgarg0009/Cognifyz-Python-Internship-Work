# Cognifyz-Python-Internship-Work
This repository contains the tasks completed during the Python Development Internship at Cognifyz IT Solutions.

## Internship Details

- Position: Python Development Intern
- Mode: Remote
- Duration: May 2026 - June 2026

---

## Level 1 Tasks

### Task 1 - String Reversal
Create a Python function that reverses a given string.

### Task 2 - Temperature Conversion
Convert temperatures between Celsius and Fahrenheit.

### Task 3 - Email Validator
Validate whether an email address is in a proper format.

### Task 4 - Calculator Program
Perform basic arithmetic operations (+, -, *, /, %).

### Task 5 - Palindrome Checker
Check whether a given string is a palindrome.

---

## Level 2 Tasks

### Task 1 - Guessing Game
Generate a random number and allow the user to guess it with hints.

### Task 2 - Number Guesser
Generate a random number within a specified range and provide feedback on guesses.

### Task 3 - Password Strength Checker
Evaluate password strength based on length, uppercase letters, lowercase letters, digits, and special characters.

### Task 4 - Fibonacci Sequence
Generate the Fibonacci sequence for a specified number of terms.

### Task 5 - File Manipulation
Read a text file and count the occurrences of each word in alphabetical order.
